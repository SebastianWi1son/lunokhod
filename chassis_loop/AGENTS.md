# AGENTS.md — lunokhod/chassis_loop 项目代理指南

## 1. 项目定位

**装配层**：把 lunokhod 的四块积木接到**同一个时间基**上，按固定顺序跑一遍。
它**不生产数据，只搬运和排列** —— 算法全部在被它调用的库里。

- 源码：`inc/chassis_loop.hpp`（**唯一对外产物**，**INTERFACE 库，没有 `.cpp`**）
- 依赖：`contracts` / `kinematics` / `odometry` / `wheel` / `twist_acc_limiter`（**它在最上层**）

## 2. 本组件特有的规矩

1. **它只吃「已算好的量」**（`Twist` / `dt` / `now`），**不碰 IO**。
   一旦它需要知道「命令从哪来」「IMU 在哪读」→ 那不是装配层，是应用层。
2. **不许自己发明时间基** —— 时间基的拥有者是调用方（固件定时器 / `hal::tick()`），
   装配层只做**分发**（把同一份 `dt`/`now` 给所有消费者）。
3. **不做判定**（不决定"该信谁 / 该怎么做"）；**不 include foucault**（跨库只传标量，
   姿态融合由使用者在库外接一根线）。
4. 加新端口前先问：**它替使用者做决定了吗？**（`../AGENTS.md` §5.3）
